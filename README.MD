## Project 2: classification & validation
In this assignment you will build and validate the classification model.

In a .csv file an eight band satellite image data data is provided and the second one contains the labels. The x and y columns are coordinates of the pixels, band1-band8 show brightness in each band and the label column shows the label, i.e. land cover in the pixels. You can choose the model algorithm, you can test multiple algorithms (not compulsory). Think which variable(s) you have to use to split the data into training and validation samples. Justify your validation approach.

1. Show the classification results using a confusion matrix and relevant accuracy/error metrics;

2. plot the image raster in true colors (red is band4, green is band3 and blue is band2) and overly it with the labels as points - map proper aesthetic to the label;

3. plot the classification prediction for all pixels, i.e. a predicted land cover map.

Describe and justify your approach in a short report; include the plots, do not include the script.

System accepts only reports in PDF files!
